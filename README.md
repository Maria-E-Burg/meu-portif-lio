## ✨ Conteúdo

- Apresentação profissional
- Sobre mim

- Formação e cursos
- Competências
- Links de contato

## 🧰 Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts

## ▶️ Como executar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Também é possível usar a extensão **Live Server** no Visual Studio Code para visualizar o site durante o desenvolvimento.

## 🚀 Publicar no GitHub e no Vercel

1. Crie um repositório público no GitHub, por exemplo `meu-portfolio`.
2. Envie os arquivos `index.html`, `styles.css`, `script.js` e `README.md` para a raiz do repositório.
3. Entre no Vercel e escolha **Add New → Project**.
4. Importe o repositório do GitHub.
5. Como é um site estático, não é necessário configurar um framework nem um comando de build.
6. Clique em **Deploy**. Depois da publicação, o Vercel fornecerá um endereço público.

## 📝 Personalização

Antes de publicar, revise os dados de contato e as informações profissionais. O telefone foi omitido da página para ajudar a preservar a privacidade.
